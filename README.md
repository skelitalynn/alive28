Slogn： 28 天陪你重启人生

为什么是 28 天？

1、重生≠1次顿悟（重建神经回路与自我关系）
1 天太短， 只能缓解痛苦，根本无法重建；
21 天 工具化训练习惯，不足以穿越情绪低谷；
1 个月太模糊没有心理闭环，缺乏完成的仪式感。

2、28天心理周期（情绪系统从防御——安全模式）
一个自然生理周期（昼夜节律 + 月相周期）； 
人类天生对 28 天有潜意识上的「重启感」；
不会吓退人，也不会敷衍自己。

3、建立人生信心（重启人生第一步）
28 天不是改变你的人生；
而是帮你重建「一定要活下去、能活下去的信心」；
重新「看见人生的希望」，陪你重新出发、启动。

人生重启三部曲：Day1-28

01/照顾自己（Self-Care｜安全感与稳定系统）
人在低谷时：神经系统是高度警觉或崩溃状态
大脑无法处理复杂意义
梦想、道理、道理都无效
所以第一步不是变好，而是：
先让自己活着不那么痛苦。
这就是： 吃饭、睡觉、呼吸、减负、
原谅自己、允许脆弱。

02/自我认可（Self-Worth｜自我价值与存在感修复）
人稍微稳定后，最大的空洞不是生活，
而是：“我的意义是什么？我的价值在哪里？”
所以必须修复的是：
自我价值感/存在即合理/努力被看见，
这就是：夸自己、喜欢自己、承认平凡、
回顾不容易、确认价值、看到成长。
存在的本身就是价值。

03/关系连接（Connection｜连接感与关系复苏）
人的重生不是不痛苦，
而是：愿意重新与世界发生连接。
不是社交热闹，
而是：能表达真实、能拒绝不想要的，
能被需要、能给予善意，
能感到世界温暖。
这是在重建：
关系、世界与他人的信任感。
